# iMini Tuner

机械革命 imini Pro 830（IMINI-ARB32H-HPT）的第三方控制工具，版本 2.2.0，界面基于 Tauri V2。

## 使用

1. 从开始菜单运行「iMini Tuner」，按提示允许管理员权限。
2. 在「模式调整」页切换静音、均衡、狂暴模式；切换后会显示「已切换到“指定模式”」通知。
3. 在「风扇调整」页先阅读免责声明并点击「我已知晓」，然后可拖动目标转速或点击「恢复自动」。
4. 主界面没有右键菜单；右键**托盘图标**可打开托盘菜单。标题栏右侧的滑杆按钮可打开设置。

## 机型

标题栏会读取并显示当前主板/机型。仅在 IMINI-ARB32H-HPT（imini Pro 830）上完成验证；如果检测到其他机型，风扇页会提示「未在当前机型下验证该功能可用性，请自行测试」。

## 风扇调整

- 「恢复自动」把风扇交回固件自动策略；退出程序时也会尝试恢复自动。
- 默认最低 35%。打开「忽视转速调节最低限制」并确认风险后，可降到 20%；20% 是程序硬下限。
- 打开最低限制后才会显示「温度保护」开关。默认开启：温度达到 88°C、或检测到风扇转速异常时，程序自动恢复固件自动风扇。
- 关闭温度保护后，程序不再自动接管风扇。请勿在关闭保护时长时间高负载运行。
- 免责声明与风险提示只是程序内的保护措施，不能覆盖断电、强制结束进程或固件异常。

## 设置

- **快捷键切换模式**：
  - 「轮换模式」只设置一个热键，默认 `Ctrl + Alt + M`，按「静音 → 均衡 → 狂暴 → 静音」轮换。
  - 「自定义三模式」可分别设置静音、均衡、狂暴热键，默认 `Ctrl + Alt + 1/2/3`。
  - 每个热键至少包含一个修饰键（Ctrl、Alt、Shift、Super）；输入框下方的修饰键名称可悬停查看定义。
- **关闭窗口后保留后台运行**：关闭按钮只隐藏窗口，后台进程继续运行。
- **显示托盘图标**：不勾选时仅隐藏托盘图标，后台进程仍然保留；关闭窗口不会退出。需要重新打开界面时，运行程序目录中的「show-window.cmd」或「show-window.ps1」。
- 只有取消「关闭窗口后保留后台运行」时，关闭窗口才会结束进程。
- 开机自启使用任务计划程序中的 `iMini Tuner` 任务，以最高权限运行，登录时不弹 UAC。
- 界面隐藏 30 秒后会释放 WebView2 渲染进程以降低后台占用；重新显示时自动创建，首次显示会稍慢。

## 数据

- 设置：`%LOCALAPPDATA%\iminiControlCenter\settings.json`
- 日志：`%LOCALAPPDATA%\iminiControlCenter\app.log`
- 固件接口/通知缓存：`%ProgramData%\iMiniTuner\run-*\`（仅 SYSTEM 与 Administrators 可访问，退出时删除本次目录）

## 卸载

在「设置 → 应用 → 已安装的应用」中找到「iMini Tuner」卸载，或运行安装目录中的 `unins000.exe`。卸载会删除快捷方式、开机自启任务、程序目录和本地设置。
